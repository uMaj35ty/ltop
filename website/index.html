ltop finds the process eating your bandwidth or disk — per process, per connection, per LAN peer — in one btop-style screen.

A terminal monitor for software and game developers, sysadmins and enthusiasts. Runs without root; an optional eBPF helper adds exact TCP and UDP byte accounting.

quick install
$ brew install uMaj35ty/ltop/ltop # macOS & Linux · prebuilt
$ cargo install ltop # from source · Rust stable
$ # or tarballs (x86_64/aarch64): github.com/uMaj35ty/ltop/releases
linux · optional eBPF accounting (per-process & per-connection bytes)
$ sudo cp ltop-bpf /usr/local/bin/ # from the same release
$ sudo cp ltop-bpf.service /etc/systemd/system/
$ sudo systemctl enable --now ltop-bpf

Features

Six boxes, one job each. Everything on screen is also machine-readable — ltop --json emits the same data as a versioned schema.

▣Six boxes, one job each

NET charts per-NIC throughput; DISK I/O plus a device tree with capacity bars; CONNS lists every socket with live per-connection B/s and totals; PROCS keeps per-process network (TCP+UDP) and disk totals for the whole session — exited processes stay on screen, grayed out, relaunchable with one key.

◉eBPF accounting: TCP and UDP

The kernel exposes no per-socket UDP counters, and sampling misses short-lived connections. The optional root helper ltop-bpf counts bytes at the send/recv syscalls (v4+v6), per pid and per socket inode; the unprivileged TUI diffs a 1-second snapshot. Without the helper, everything else keeps working.

⌬Made for AI agents

ltop --json / --schema for one-shot questions; ltop watch records a window headlessly and ltop report --json returns exact sums and peaks — a 10-minute window costs ~1k tokens instead of ~40k. Agent skill included.

⌂LAN neighbours with traffic

Passive ARP plus a periodic UDP knock finds devices on your subnet (IP, MAC, mDNS hostname, gateway flag). Each neighbour shows its live connection count, rate and bytes — enter pins it and filters CONNS to that peer.

◐72 btop themes, Omarchy follow

Any btop theme file loads as-is; 72 are built in and switchable at runtime. On Omarchy ltop follows the desktop theme, and --follow-theme re-colors it while running. UI in English or Chinese (lang = zh).

⭓Linux + macOS, no root

x86_64 and aarch64; prebuilt for glibc 2.35+. The TUI runs unprivileged; macOS reads native sources (nettop, IOKit, route socket). Verified per release in QEMU/KVM on five distributions — SELinux enforcing included — and on Apple Silicon hardware.
