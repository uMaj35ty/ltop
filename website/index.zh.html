流量去哪了？谁在吃你的磁盘？

ltop 一屏揪出吃带宽、吃磁盘的进程——按进程、按连接、按局域网对端。

面向软件与游戏开发者、系统管理员和折腾爱好者的终端监控。主程序免 root； 可选 eBPF 助手补齐精确的 TCP/UDP 字节计费。

快速安装
$ brew install uMaj35ty/ltop/ltop # macOS 与 Linux · 预编译
$ cargo install ltop # 源码编译 · Rust stable
$ # 或 tarball（x86_64/aarch64）：github.com/uMaj35ty/ltop/releases
仅 Linux · 可选 eBPF 计费（每进程/每连接字节）
$ sudo cp ltop-bpf /usr/local/bin/ # 与 TUI 同一 release
$ sudo cp ltop-bpf.service /etc/systemd/system/
$ sudo systemctl enable --now ltop-bpf

功能

六盒各司一职。屏幕上的每一项都同时是机器可读的——ltop --json 输出同一份数据，schema 随版本。

▣六盒，各司一职

NET 出每网卡吞吐图表；DISK I/O 加设备树与容量条；CONNS 列出系统全部 socket，逐连接实时 B/s 与总量；PROCS 记每进程整场的网络（TCP+UDP）与磁盘 总量——退出的进程灰显保留，一键重启。

◉eBPF 计费：TCP 和 UDP

内核不给逐 socket 的 UDP 字节，抽样又会漏掉短命连接。可选的 root 助手 ltop-bpf 在 send/recv 系统调用（v4+v6）处按 pid 和 socket inode 计数；免特权的 TUI 每秒 diff 一份快照。没有助手，其余功能照常。

⌬为 AI 而生

一次性问题用 ltop --json / --schema；时间窗用 ltop watch 无头录制、ltop report --json 给出精确 总和与峰值——10 分钟窗口约 1k token，轮询要 4 万。配套 agent skill。

⌂带流量的 LAN 邻居

被动 ARP 加周期 UDP knock，自动发现子网设备（IP、MAC、mDNS 主机名、 网关标记）。每个邻居带实时连接数、速率和字节——enter 置顶它， CONNS 只看这个对端。

◐72 套 btop 主题，跟随 Omarchy

任何 btop 主题文件直接可用；内嵌 72 套随时切换。Omarchy 下跟随桌面 主题，--follow-theme 让运行中的 ltop 实时变色。界面英文或 中文（lang = zh）。

⭓Linux + macOS，免 root

x86_64 与 aarch64；预编译覆盖 glibc 2.35+。TUI 免特权运行；macOS 读 原生源（nettop、IOKit、路由 socket）。每个 release 在 QEMU/KVM 五个 发行版（含 SELinux enforcing）与 Apple Silicon 实机验证。

快速上手

三条命令从零到看清全局。页脚永远显示当前可用键；m → help 是完整键位表。

1

安装

Homebrew 预编译、cargo 源码编译或 release tarball——全部渠道。

$ brew install uMaj35ty/ltop/ltop

macOS 27? 跑一次 ltop lan-setup——LAN/NET 盒即显示真实 MAC(每用户代理,免 root)。

2

运行，按这几个键

Tab 布局 · / 搜索 · enter 详情面板 · pcl 单焦点 · z 缩放 · 1–6 开关盒子 · space 暂停 · m 菜单。

$ ltop

★

给 agent：先 watch 再 report

无头录制一个时间窗，得到按进程/按连接的精确总和与峰值（~2 KB JSON） ——比轮询省 ~97% token。

$ ltop watch --duration 10m --proc chrome
